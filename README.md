# Zork I — Edizione italiana

Primo capitolo web, bilingue nei comandi (italiano e inglese), di una localizzazione incrementale di **Zork I**.

## Avvio

Non richiede dipendenze. Apri `index.html` in un browser oppure esegui un server statico nella cartella:

```sh
python3 -m http.server
```

Poi visita `http://localhost:8000`.

## Stato del capitolo

Giocabili: esterno della casa, cassetta delle lettere, cucina e soggiorno. Prova `APRI CASSETTA`, `PRENDI VOLANTINO`, `LEGGI VOLANTINO`, `OVEST`, oppure i rispettivi comandi inglesi.
