# Sorgenti ZIL per Zork I in italiano

Questa directory contiene una copia di lavoro dei sorgenti ZIL MIT di
[`historicalsource/zork1`](https://github.com/historicalsource/zork1).

La traduzione avviene qui, per aree giocabili. Il prototipo web corrente non
carica ancora questo codice: non verrà sostituito finché il capitolo "Esterno e
casa bianca" non sarà completo e verificato in italiano.

Per compilare un file Z-machine con ZILF e Docker:

```sh
./scripts-build-zork-it.sh
```

Il comando produce `source/zork-it/zork1.z3` (ignorato da Git).
